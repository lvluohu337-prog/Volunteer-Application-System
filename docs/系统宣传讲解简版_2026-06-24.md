# 歪歪志愿馆系统宣传讲解简版

## 1. 一句话讲清楚

歪歪志愿馆是一套高考志愿填报辅助系统：先分析学生适合什么专业方向，再结合真实招生数据判断能报哪些院校和专业，最后生成可讲解、可导出的志愿规划报告。

可以这样对外说：

> 我们不是只查分数线，而是把“孩子适合什么”和“这个分数现实能报什么”结合起来，帮家长做更清楚的志愿决策。

## 2. 系统主要解决什么问题

家长常见的痛点：

- 不知道孩子到底适合什么专业，只能跟风选热门。
- 只看学校名气，忽略专业、城市、就业方向和录取风险。
- 网上信息太散，分数线、位次、招生计划、选科要求很难一起判断。
- 咨询老师讲方案时，需要一份能展示、能复核、能交付的报告。

系统的作用：

- 帮老师把学生信息、成绩、位次、兴趣和家庭偏好统一整理。
- 用学生画像辅助判断专业方向。
- 用真实招生数据筛选院校专业。
- 把结果整理成冲刺、稳妥、保底和第一志愿建议。
- 生成 PDF / Word 报告，方便给家长讲解和留档。

## 4. 系统操作流程

1. 打开工作台：说明系统主流程是“录入学生 -> 画像分析 -> 分数定位 -> 志愿方案 -> 报告导出”。
2. 打开学生录入：展示生日、时辰、成绩、位次、选科、兴趣、家庭偏好等字段。
3. 打开学生工作台：说明每个学生都有独立处理流程。
4. 打开专业推荐：讲“系统会先看孩子适合什么方向”。
5. 打开志愿方案：讲冲刺、稳妥、保底如何分层。
6. 打开报告页：重点展示 399 标准版、正式推荐表、第一志愿建议、风险提示。
7. 点击 PDF / Word 导出：说明报告可以交付给家长复核。

## 5. 给老师的推荐话术

### 开场话术

> 家长最关心的其实是两个问题：孩子适合什么专业，以及这个分数到底能报哪些学校。我们的系统就是把这两件事放在一起判断。

### 讲系统价值

> 系统会先根据学生信息形成画像，辅助判断专业方向；再结合真实招生数据，看分数、位次、选科和历史录取情况，筛出更现实的院校专业方案。

### 讲报告交付

> 最后系统会生成一份报告，里面有专业方向、院校专业推荐表、冲稳保分层、第一志愿建议和风险提示。老师可以在此基础上补充人工意见，再给家长讲解。

### 讲老师角色

> 系统不是替代咨询老师，而是把数据整理、初步筛选和报告底稿先做好，让老师把精力放在最终判断和家长沟通上。

## 6. 宣传时重点突出什么

推荐重点：

- **方向更清楚**：不只是问“能上哪”，还要看“适合学什么”。
- **数据更扎实**：结合真实招生数据、分数、位次、选科和历史录取情况。
- **结果更具体**：能落到院校、专业、城市、最低分、最低位次和风险提示。
- **报告可交付**：支持网页展示和 PDF / Word 导出。
- **老师可复核**：系统给出底稿，老师做最终判断和个性化沟通。

## 7. 不能这样宣传

| 不要说 | 应该说 |
|---|---|
| 保录取、包录取、必中 | 辅助判断录取风险，最终以官方投档结果为准 |
| 八字决定录取 | 画像只辅助专业方向和沟通解释，录取判断看分数、位次和招生数据 |
| 全国都能做正式报告 | 目前正式范围先聚焦河南 |
| 系统自动替代老师 | 系统辅助老师，提高效率和方案清晰度 |
| 100% 准确 | 基于历史数据和规则做风险评估，不承诺最终结果 |

## 9. 3 分钟讲解稿

我们这个系统主要是帮高考生和家长做志愿填报辅助决策。它不是简单查分数线，而是先看孩子适合什么方向，再看这个分数和位次现实能报哪些学校和专业。

第一步，老师会录入学生的生日、时辰、选科、分数、位次、兴趣和家庭偏好。系统会形成学生档案，并生成画像分析，用来辅助判断孩子更适合技术型、研究型、稳定型、表达型还是服务型等方向。

第二步，系统会结合真实招生数据做筛选，包括院校、专业、招生计划、历史最低分、最低位次和选科要求。这样出来的结果不是一句泛泛的建议，而是具体到哪些院校、哪些专业、属于冲刺、稳妥还是保底。

第三步，系统会生成报告。报告里有专业方向、院校专业推荐表、第一志愿建议、风险提示和老师备注。报告可以导出 PDF 或 Word，方便家长带回去复核。

需要强调的是，系统不承诺录取，也不替代老师。它的价值是把学生画像、真实招生数据和老师经验结合起来，让家长更清楚地做选择。

## 10. 给推广老师的提醒

- 先讲“解决家长焦虑”，再讲系统功能。
- 多讲“具体院校专业推荐表”，少讲纯技术。
- 一定要强调“不承诺录取”，这样更专业，也更安全。
- 演示时优先展示 399 标准版报告，因为它最像正式交付物。
